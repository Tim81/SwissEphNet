Sidecar log for scripts/freeze-manifest.tsv, checked by scripts/verify-freeze-log.ps1.

scripts/verify-freeze.ps1 -Update rewrites scripts/freeze-manifest.tsv from whatever is
currently on disk, with nothing else requiring that rewrite to be reviewed alongside a
real reason. Tests/baseline/*.tsv has exactly this same failure mode and closes it with
Tests/baseline/baseline-*.env.txt's own "## Local regenerations" log, checked by
scripts/verify-baseline-log.ps1; this file and scripts/verify-freeze-log.ps1 are the
identical mechanism for the freeze manifest. Never add an entry here to make a failing
freeze gate pass without first understanding why it failed -- see CONTRIBUTING.md and
scripts/verify-freeze.ps1's own header for what a legitimate change to a frozen file
looks like (a fidelity fix citing the C, or a re-transliteration).
